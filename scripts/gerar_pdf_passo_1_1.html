2. Decisões de Arquitetura Registradas (ADRs do Passo 1.1)

ADR 005 — Adoção de Python 3.12 Hermético via `uv`:
Embora o host possua o Python 3.14.7, o projeto adotará formalmente o Python 3.12 isolado via uv venv --python 3.12 no Passo 1.2. Isso assegura 100% de paridade com o container Docker de produção (python:3.12-slim) e garante disponibilidade de wheels pré-compilados para Django, Celery e LangGraph.
ADR 006 — Arquitetura Cloud-Native / VPS-First:
Aprovada a estratégia de manter o computador local como estação de trabalho ágil (código, testes rápidos e Git) e concentrar a malha de containers (Docker Swarm, Traefik, PostgreSQL, Redis e RabbitMQ) diretamente na VPS Hostinger Ubuntu Linux nos Passos 5 a 8, economizando RAM local e eliminando atritos de virtualização.
ADR 007 — Proteção de Scripts Linux via `.gitattributes`:
Diante do core.autocrlf = true no Windows, o projeto adotará um arquivo .gitattributes forçando que arquivos de script (*.sh) mantenham quebras de linha LF, impedindo falhas de execução no Docker.
