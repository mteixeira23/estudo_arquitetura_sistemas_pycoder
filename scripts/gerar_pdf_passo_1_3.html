2. Arquitetura do Harness de Qualidade

⚡ Linter & Formatter: Ruff 0.16.8

  • Motor: Compilado nativamente em Rust, executando em espaço de usuário dentro de .venv\Scripts\ruff.exe.
  • Performance: Análise estática do projeto completo em 15ms (10x a 100x mais veloz que flake8/black).
  • Organização de Imports: Algoritmo determinístico isort separando Standard Library, Third-Party (Django/Celery) e First-Party (core, apps, config).
  • Modernizador Automático: Regra UP audita sintaxe obsoleta e converte para Python 3.12 nativo.

🧪 Framework de Testes: Pytest 9.1 & Cobertura

  • Strict Mode: --strict-markers proíbe marcadores não mapeados, eliminando falhas silenciosas por erros de digitação.
  • Taxonomia Semântica: Separação expressa entre testes unitários rápidos e testes de integração com containers.
  • Branch Coverage: Monitoramento com coverage.py analisando todos os ramos condicionais (if/else).
  • Assert Rewriting: Diagnóstico enriquecido de variáveis em tempo de execução nas falhas de teste.

4. Decisões Arquiteturais Consolidadas (ADRs)

Decisão Técnica Racional Arquitetural Impacto no Deploy / Produção
Modo Aplicação (tool.uv package=false) Sistemas Django/Celery são aplicações web e não pacotes distribuíveis no PyPI. Evita overhead de build de wheels. Deploy via Dockerfile simplificado: uv sync --frozen --no-dev sem dependências de compilação C/Rust.
Teto de Runtime (<3.13) Impede o uso inadvertido de versões preliminares (como Python 3.14 do host) que quebram pacotes compilados. Garante paridade 1:1 rigorosa com os containers oficiais python:3.12-slim que rodarão na VPS Hostinger.
Lockfile Multiplataforma (uv.lock) Contém hashes SHA-256 calculados simultaneamente para Windows x86_64, Linux glibc x86_64 e Linux aarch64. Na VPS Ubuntu, uv sync --frozen nunca re-resolve pacotes; baixa exatamente as mesmas versões auditadas localmente.
